# Healthcare EDA and Results

The project uses the UCI Heart Disease dataset as a reproducible benchmark. UCI reports 303 instances and 13 input features, with classification as the associated task. Missing values are documented for `ca` and `thal`.

## Analysis
- Target distribution
- Age and blood-pressure distributions
- Cholesterol and maximum-heart-rate distributions
- Risk by chest-pain category
- Correlation analysis
- ROC-AUC and classification report
- Threshold analysis for false-negative reduction

The model is a portfolio/research demonstration and is not a clinical decision-support system.

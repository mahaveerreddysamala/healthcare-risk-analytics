# Healthcare EDA

This project uses the UCI Heart Disease dataset. UCI reports 303 instances, 13 features, classification as the associated task, and health/medicine as the subject area. citeturn0search1turn0search5

## Analysis checklist
1. Load the processed Cleveland data.
2. Convert missing-value markers to `NaN`.
3. Create a binary target: disease present vs absent.
4. Profile age, resting blood pressure, cholesterol and maximum heart rate.
5. Compare disease prevalence by chest-pain category and exercise-induced angina.
6. Plot feature distributions.
7. Save figures under `reports/figures/`.

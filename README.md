# Healthcare Risk Analytics

Predictive analytics solution for identifying patients at elevated risk of an adverse outcome using structured clinical and demographic data.

## Stack
Python · Pandas · SQL · Scikit-learn · XGBoost · SHAP · Streamlit

## Workflow
Data quality → exploratory analysis → clinical feature engineering → model training → cross-validation → threshold optimization → explainability → dashboard.

## Responsible ML
The project tracks class imbalance, false-negative risk, feature leakage, and model interpretability. It is intended for analytics and research demonstration, not clinical decision-making.

## Outputs
- Risk probability
- Risk tier
- Model performance metrics
- Feature importance / SHAP explanations
